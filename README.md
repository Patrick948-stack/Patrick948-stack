### Featured Projects

**DuckPath** is an AI powered career guidance platform that turns job titles into personalized learning roadmaps. It started as a Streamlit MVP and grew into a production full stack app with a FastAPI backend and a Next.js/TypeScript frontend, including JWT auth, rate limiting, an LLM based skill extraction pipeline, over 85 percent backend and 70 percent frontend test coverage, and a GitHub Actions CI/CD pipeline.

**Uni Tracker** is a full stack React 19 and TypeScript app for tracking college applications across 5 to 20 schools, with guided checklists, command palette navigation, and real time theming. It uses Zustand and localStorage for backend free state management, backed by a Playwright end to end test suite and automated CI/CD.

**Compass** is a Slack based student support agent built with Node.js, Slack Bolt, the Groq API, and Supabase, which helps students ask advising questions, find study partners, and connect with campus resources through AI powered workflows.

**ESPI Research Software** is a cross platform Python desktop application built with PyQt5, OpenCV, and PyVISA for a physics research lab, replacing an expensive proprietary LabVIEW workflow with a free, in house alternative compatible with hundreds of camera models.

**Tutor Match** is a single page web app connecting students with tutors, featuring a multi role system for students, tutors, and admins, an intelligent tutor auto assignment algorithm, and end to end lifecycle workflows built with vanilla JavaScript.

**CS Commons Door Sensor** is an embedded security device on an ESP32-S3 with ultrasonic intrusion detection and a Bluetooth Low Energy notification layer.
